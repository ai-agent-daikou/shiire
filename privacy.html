プライバシーポリシー

AIエージェント代行サービス（屋号：万事楼、以下「当サービス」）は、お客様の情報を次のとおり取り扱います。

1. 取得する情報

お店のオーナー様の許可を得たうえで、Google ビジネス プロフィール API を通じて、お店の基本情報、口コミ、口コミへの返信、投稿、写真の情報を取得します。

2. 利用目的

取得した情報は、お店のオーナー様に代わって、口コミへの返信文の作成・送信、投稿や写真の管理、口コミの集計レポートの作成のためだけに使います。

3. 第三者への提供

取得した情報を販売したり、広告に使ったり、法令に基づく場合を除いて第三者に渡したりすることはありません。

4. Google API から受け取った情報について

Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

5. 保管と削除

情報は、お店のオーナー様の Google アカウント内（Google スプレッドシート・Apps Script）に保管します。Google アカウントの「サードパーティ製のアプリとサービス」から、当サービスへのアクセス許可をいつでも取り消せます。削除のご依頼は下記までご連絡ください。
